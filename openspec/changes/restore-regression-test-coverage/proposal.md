# Proposal

## Why

Текущие служебные инструкции ограничивают автоматические и регрессионные проверки только изменёнными inputs и запрещают полный повторный набор. Пользователь 02.10.2026 поручил удалить эти ограничения из проектных правил и постоянной памяти, затем предложить недостающие тесты по фактическому коду.

## What Changes

- Удалить ограничения количества и ширины тестов из действующих служебных документов; сохранить точные identities, историю результатов, disposable data и проверяемый build cache.
- Обновить постоянную память через поддерживаемую корректирующую запись, отменяющую прежние общие требования минимизации тестирования.
- Сопоставить текущие frontend/backend сценарии и wiring CI с тестами, подготовить приоритетный отчёт с конкретными пробелами и критериями проверки.

## Capabilities

### New Capabilities

Нет. Только документация, обновление памяти и анализ покрытия; `skip_specs: true`.

### Modified Capabilities

Нет изменений поведения продукта. Реализация предложенных тестов в это задание не входит.
