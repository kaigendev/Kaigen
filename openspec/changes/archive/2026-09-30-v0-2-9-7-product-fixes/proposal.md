# Proposal

## Why

В Web-версии полоса прокрутки перекрывает выбранный раздел, служебная область не следует языку приложения, а ограничение 900 × 660 блокирует малые окна. После выпуска v0.2.9.6 на production был принят срок жизни Web-пространства 72 часа; опубликованный установщик ещё задаёт 24 часа и при следующем развертывании вернёт прежнее значение. В чате нельзя удалить отдельное сообщение только из своей истории; уведомление об успешном сборе дополнительной энтропии исчезает слишком быстро.

## What Changes

- Переместить полосу прокрутки разделов настроек в свободную область у подвижной границы без изменения остальной геометрии.
- Синхронизировать язык служебной области Web с выбранным языком приложения и снять блокировку браузера при размере меньше 900 × 660.
- Закрепить уже принятую 72-часовую настройку Web-пространства в установщике v0.2.9.7, чтобы развертывание не возвращало 24 часа.
- Добавить последним пунктом контекстного меню удаление выбранного сообщения из локальной истории без подтверждения и без обращения к собеседнику. Удалять доставленные и ожидающие сообщения, реакции и цитируемые сообщения; ожидающую отправку удалять также из очереди. При отсутствии цитируемого сообщения выводить локализованный текст «цитируемое сообщение не найдено».
- Увеличить показ сообщения об успешном сборе дополнительной энтропии на 2 секунды.
- После адресных проверок подготовить v0.2.9.7, зарегистрировать квитанцию Windows test set и синхронизировать макетную систему по штатному release route; затем выпустить релиз и обновить production.

## Capabilities

### New Capabilities

- `web-shell`: Геометрия меню, язык служебной области, доступность Web в малом окне и сохранение принятого срока жизни пространства при установке.
- `local-message-deletion`: Локальное удаление одного сообщения с учётом истории, цитат, очереди и обмена ключами.
- `pq-entropy-feedback`: Длительность уведомления об успешном сборе дополнительной энтропии.

### Modified Capabilities

Нет: OpenSpec инициализирован для этой задачи, ранее описанных capabilities нет.

## Impact

Затронуты общий React-интерфейс, Web-оболочка и её установщик, локальное хранение истории и очередь отправки. Протокол между клиентами для удаления не вводится. Нужны адресные регрессии изменённых сценариев, синхронизация макета перед выпуском по release route, выпуск v0.2.9.7 и production readback.
