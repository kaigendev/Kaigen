# Spec Delta

## Purpose

Сохранять соответствие видимого индикатора языка Windows фактическому вводу в Kaigen сразу после запуска, без ручного сворачивания и разворачивания окна.

## ADDED Requirements

### Requirement: Startup language indicator follows real input

Windows desktop SHALL позволять системному индикатору языка отражать фактическую раскладку при первом вводе на экране разблокировки профиля после запуска.

#### Scenario: First switch in the unlock password field
- **WHEN** пользователь запускает клиент, выбирает поле пароля и переключает системную раскладку RU/EN
- **THEN** фактически вводимые символы и видимый системный индикатор соответствуют выбранной раскладке до любого сворачивания, разворачивания или восстановления из трея

#### Scenario: Return from tray and normal minimize
- **WHEN** пользователь возвращается в окно из собственного трея либо после обычного сворачивания
- **THEN** переключение RU/EN и системный индикатор продолжают работать на экране разблокировки и после перехода к открытому профилю

### Requirement: Startup recovery respects foreground ownership

Исправление нативного фокуса SHALL сохранять выбор раскладки Windows, не перехватывать foreground другого приложения и не выполнять бесконечное повторное восстановление.

#### Scenario: Startup finishes in the background
- **WHEN** окно другого приложения получает foreground до окончания загрузки Kaigen
- **THEN** Kaigen не отбирает у него фокус и обеспечивает корректный ввод после явного возвращения пользователя

#### Scenario: Window changes before queued recovery
- **WHEN** окно скрыто, минимизировано, уничтожено либо заменено до выполнения отложенного действия
- **THEN** действие не переносит фокус на устаревшее или неактивное окно

#### Scenario: Repeated focus and readiness events
- **WHEN** поступают повторные события готовности или фокуса одного окна
- **THEN** восстановление не вызывает цикл событий и не сбрасывает текущую раскладку либо пользовательский ввод
