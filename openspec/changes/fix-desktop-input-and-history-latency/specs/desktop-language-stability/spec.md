# Spec Delta

## Purpose

Сохранить возможность переключения Windows-раскладки и видимый системный индикатор при вводе сообщения и разблокировке профиля.

## ADDED Requirements

### Requirement: Клиент не управляет выбранной пользователем раскладкой
Desktop SHALL не устанавливать, не восстанавливать и не синхронизировать Windows keyboard layout по событиям focus, клавиш или таймерам. Выбор раскладки SHALL оставаться у Windows и пользователя.

#### Scenario: Переключение пользователем
- **WHEN** пользователь переключает RU/EN в сфокусированном поле
- **THEN** клиент не выполняет автоматическую активацию ранее наблюдённой или вычисленной раскладки

### Requirement: Одинаковое поведение обоих полей ввода
Desktop SHALL сохранять возможность переключения раскладки как в поле сообщения, так и в поле пароля разблокировки профиля, не читая и не сохраняя введённый пароль.

#### Scenario: Поле сообщения
- **WHEN** пользователь переключает RU/EN в сфокусированном поле сообщения
- **THEN** последующий ввод использует выбранную раскладку без отката

#### Scenario: Разблокировка профиля
- **WHEN** пользователь переключает RU/EN в сфокусированном поле пароля профиля
- **THEN** последующий ввод использует выбранную раскладку без отката

### Requirement: Первое переключение после восстановления из трея работает
Desktop SHALL после явного восстановления собственного окна из notification area сохранять переключение RU/EN и соответствующий ему видимый системный индикатор без дополнительного сворачивания, прокрутки или смены фокуса.

#### Scenario: Возврат из трея
- **WHEN** пользователь скрывает и восстанавливает клиент через его собственную иконку трея, затем переключает RU/EN
- **THEN** поле разблокировки или сообщения получает символ выбранной раскладки, а видимый системный индикатор соответствует ей

#### Scenario: Завершённый клик
- **WHEN** пользователь завершает один левый клик по иконке трея
- **THEN** клиент выполняет ровно одно скрытие или восстановление собственного окна
