# Spec Delta

## Purpose

Отображать новое входящее или отправленное сообщение сразу в его месте, сохраняя виртуализацию, актуальный чат и пользовательскую позицию чтения.

## ADDED Requirements

### Requirement: Готовые сообщения появляются в корректном диапазоне
Клиент SHALL отображать готовые сообщения в актуальном диапазоне истории без пустого зарезервированного хвоста при следовании новым сообщениям; поздние ответы старого чата SHALL отбрасываться. Пользовательская прокрутка старой истории SHALL сохраняться.

#### Scenario: Новый хвост
- **WHEN** новое сообщение поступает при следовании хвосту
- **THEN** сообщение появляется над полем ввода без ожидания ручной прокрутки

#### Scenario: Пользователь читает историю
- **WHEN** сообщение поступает при чтении старой части истории
- **THEN** клиент сохраняет место чтения и не принуждает переход к хвосту

#### Scenario: Отправленное сообщение
- **WHEN** пользователь отправляет сообщение
- **THEN** сообщение отрисовывается в предназначенном месте без необходимости ручной прокрутки

#### Scenario: Поздний ответ старого чата
- **WHEN** ответ истории приходит после смены чата
- **THEN** ответ не создаёт пустое место и не заменяет сообщения нового чата
