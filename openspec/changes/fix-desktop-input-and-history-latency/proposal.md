# Proposal

## Why

В desktop сохраняются два независимых дефекта: невозможность переключить раскладку при вводе сообщения и разблокировке профиля; новое входящее или отправленное сообщение создаёт пустое место до задержки или прокрутки. Каждый дефект требует отдельной причинной проверки и исправления; общая причина не предполагается.

## What Changes

- Сохранить выбранную пользователем раскладку Windows при вводе сообщения и разблокировке профиля, включая задержанную очередь наблюдений.
- Исправить доказанные причины задержки публикации и отображения истории, включая работу с вложениями и диапазоном виртуализации.
- Добавить регрессии очередей, устаревших ответов, смены чата и отказов; проверить desktop на disposable данных с включённой и выключенной орфографией.
- Завершить обычный маршрут точным Windows portable и обновлением локального Web Lab с отдельными receipts.

## Capabilities

### New Capabilities

- `desktop-language-stability`: раскладка Windows не откатывается при вводе сообщения и пароля профиля; синхронизация ограничена актуальным сфокусированным вводом.
- `chat-history-publication`: новое входящее или отправленное сообщение отображается без пустого диапазона вместо актуального хвоста.

### Modified Capabilities

Нет изменений существующих OpenSpec capabilities. Контракт общей истории остаётся согласован с локальным CHAT-BEHAVIOR.md.

## Impact

Затронуты keyboard bridge RootApp/inputLanguageSync, native input_language, публикация и отображение новых сообщений, соответствующие регрессии. Язык интерфейса в настройках, новые dependencies, версия, release и production не входят в задачу. Исходный Git HEAD: 1060a86d6f0a997fb3db510baf98716ce6f24219, рабочее дерево было чистым.
