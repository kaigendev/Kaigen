Kaigen работает только в portable-режиме.

Поддерживаемая платформа: 64-разрядные Windows 10 и Windows 11.
Установка Node.js, Rust, Visual Studio, Visual C++ Redistributable и WebView2 Runtime не требуется.
Необходимый Microsoft WebView2 Fixed Runtime уже находится в папке WebView2Runtime.
Официальный Tor Expert Bundle уже находится в папке TorExpertBundle; установленный в Windows Tor не требуется и не используется.

Каждый профиль создаётся в отдельном каталоге profiles\<id> с новым Tox ID и выбранным пользователем ником.
Дополнительные профили хранятся в папке profiles. Все настройки, контакты, полная история, черновики, ключи, очереди передач и аватары хранятся в data или в data-каталоге соответствующего профиля.
Все полученные и сохранённые файлы находятся в папке downloads.

Чтобы перенести приложение на другой компьютер, закройте его и скопируйте всю папку целиком.
Не переносите только EXE отдельно от profiles, data, downloads, runtime, toxcore.dll, WebView2Runtime и TorExpertBundle.

Tor включён по умолчанию. Приложение использует собственный процесс Tor и два динамических нестандартных локальных порта, поэтому не конфликтует с Tor Browser. Tox подключается только после 100% готовности Tor и не переключается на прямое соединение при ошибке Tor.

Папка Kaigen.exe.WebView2 содержит только служебный кэш интерфейса. Для продолжения работы она не обязательна: при отсутствии будет создана заново.
