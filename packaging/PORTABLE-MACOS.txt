Kaigen для macOS поставляется как универсальное приложение для Apple Silicon
и Intel, а также как DMG.

Portable-режим macOS требует, чтобы Kaigen.app находился в каталоге, доступном
текущему пользователю для записи. Рекомендуемый вариант:

  ~/Applications/Kaigen-portable/Kaigen.app

При первом запуске рядом с Kaigen.app создаётся единый каталог
Kaigen-portable-data. В нём находятся data, profiles и downloads со всеми
настройками, профилями, историей, черновиками, PQ-ключами и очередями.

DMG доступен только для чтения. При двойном клике на Kaigen.app внутри DMG
приложение без Terminal и запроса пароля копирует целую папку Kaigen-portable
(Kaigen.app вместе с Kaigen-portable-data) в
~/Applications/Kaigen-portable и сразу перезапускает writable-копию. Если там
уже есть полный portable-каталог, он только запускается: приложение никогда не
сливает и не перезаписывает существующие профили или данные. Неполная либо
прерванная установка блокирует автоматическую копию вместо скрытой замены.
Даже если существующая Kaigen.app старее приложения в DMG, автоматический
bootstrap её не заменяет; обновление выполняется явной заменой только
Kaigen.app после закрытия приложения.

Папку Kaigen-portable по-прежнему можно вручную перетащить из DMG в любой
writable-каталог. Установка одного Kaigen.app в /Applications не рекомендуется:
обычный пользователь может не иметь права создать рядом portable-каталог
данных.

Официальный Tor Expert Bundle для обеих архитектур включён в Kaigen.app.
Системный Tor и Homebrew конечному пользователю не нужны. Интерфейс использует
штатный WebKit macOS.

Для переноса закройте Kaigen и скопируйте Kaigen.app вместе с соседним
Kaigen-portable-data. Для обновления замените только Kaigen.app.

Внутренний исполняемый файл и CFBundleExecutable называются Kaigen. Публичная
click-to-run сборка должна быть подписана Developer ID, иметь
Hardened Runtime и нотарификационный ticket Apple. Локальная сборка без
Developer ID подписывается ad-hoc. Если macOS поместила такой тестовый архив в
карантин и не предлагает открыть приложение через контекстное меню «Открыть»,
после проверки SHA-256 удалите карантин локально:

  xattr -dr com.apple.quarantine Kaigen.app
