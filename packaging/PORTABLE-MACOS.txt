Kaigen для macOS поставляется как универсальное приложение для Apple Silicon
и Intel, а также как DMG.

Portable-режим macOS требует, чтобы Kaigen.app находился в каталоге, доступном
текущему пользователю для записи. Рекомендуемый вариант:

  ~/Applications/Kaigen-portable/Kaigen.app

При первом запуске рядом с Kaigen.app создаётся единый каталог
Kaigen-portable-data. В нём находятся data, profiles и downloads со всеми
настройками, профилями, историей, черновиками, PQ-ключами и очередями.

Не запускайте Kaigen прямо из смонтированного DMG: образ доступен только для
чтения. Скопируйте Kaigen.app в собственный writable-каталог. Установка в
/Applications не рекомендуется для portable-режима, так как обычный
пользователь может не иметь права создать соседний каталог данных.

Официальный Tor Expert Bundle для обеих архитектур включён в Kaigen.app.
Системный Tor и Homebrew конечному пользователю не нужны. Интерфейс использует
штатный WebKit macOS.

Для переноса закройте Kaigen и скопируйте Kaigen.app вместе с соседним
Kaigen-portable-data. Для обновления замените только Kaigen.app.

Сборка без Apple Developer ID подписывается ad-hoc. Если macOS поместила
скачанный архив в карантин и не предлагает открыть приложение через контекстное
меню «Открыть», после проверки SHA-256 удалите карантин локально:

  xattr -dr com.apple.quarantine Kaigen.app
