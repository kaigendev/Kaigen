# Kaigen

Kaigen — независимый переносимый клиент Tox для Windows 10/11 x64, Debian x64 и macOS 11+ на Tauri 2, React и `c-toxcore`. Исходный код, инструкции и выпуски проекта находятся в репозитории [kaigendev/Kaigen](https://github.com/kaigendev/Kaigen).

## Возможности

- стандартное сквозное шифрование Tox и дополнительный слой PQ v2: ML-KEM-768 + X25519, отдельные ключи сообщений и сохранение очереди между двумя клиентами Kaigen;
- несколько одновременно подключённых профилей с независимыми контактами, историей, черновиками, очередями и счётчиками событий;
- текстовые сообщения, изображения и файлы, включая вставку изображения или файла напрямую из буфера обмена;
- полная локальная история, экспорт переписки, сохранение черновика для каждого контакта и проверка орфографии RU/EN без блокировки ввода;
- встроенный Tor Expert Bundle, мосты Snowflake/obfs4/WebTunnel, SOCKS5-прокси и прямое подключение;
- русский и английский интерфейс, системные уведомления и трей;
- portable-хранение пользовательских данных рядом с приложением на каждой поддерживаемой ОС.

Постквантовый слой доступен только после автоматической взаимной идентификации двух клиентов Kaigen. Предложение, подтверждение, отзыв, отказ и согласованное отключение отображаются как служебные карточки в истории чата. Стандартное Tox E2EE продолжает защищать транспорт независимо от состояния дополнительного слоя.

## Готовые выпуски

Готовые пакеты для Windows, Debian и macOS публикуются на странице [Releases](https://github.com/kaigendev/Kaigen/releases). Для Windows доступны portable ZIP и MSI-установщик с выбором каталога; MSI разворачивает тот же чистый portable-набор и не переносит пользовательские данные в системные каталоги. Debian-пакет содержит AppImage. macOS-пакет содержит универсальные `Kaigen.app` и DMG для Intel и Apple Silicon. Публичный click-to-run пакет подписывается Developer ID и нотарифицируется Apple; ad-hoc подпись предназначена только для локальных тестовых сборок.

Приложение всегда работает в portable-режиме:

- каждый профиль и его закрытый ключ Tox хранятся в отдельном каталоге `profiles\<id>`;
- дополнительные профили находятся в `profiles`, а их список — в `data\profiles.json`;
- настройки, контакты, полная история, черновики, счётчики событий, PQ-ключи, очереди передач и аватары находятся в соответствующем portable-каталоге профиля;
- входящие и сохранённые файлы находятся в `downloads`;
- в Windows файлы фиксированной среды Microsoft WebView2 находятся непосредственно в `WebView2Runtime`; сборка и запуск отклоняют слишком глубокий путь, который мог бы привести к падению WebView и пустому окну, а Linux/macOS используют штатный WebKit соответствующей ОС;
- официальный Tor Expert Bundle находится в `TorExpertBundle` и не использует установленный в системе Tor;
- перенос выполняется копированием всей папки приложения после его закрытия; на macOS данные находятся в `Kaigen-portable-data` рядом с `Kaigen.app`.

Если профили не найдены, Kaigen показывает приветственный экран: можно создать новый профиль (по умолчанию с ником `Tox User`) или импортировать qTox-профиль вместе с историей. Каждый созданный или импортированный профиль получает отдельный каталог `profiles\<id>` с файлом `.tox` и собственным подкаталогом `data`. Защищённые профили используют совместимый с qTox формат `toxEsave` и сохраняются атомарно.

Все разблокированные профили работают с сетью одновременно. Переключатель аккаунтов меняет только показанные в окне данные и не перезапускает соединение. Для всех профилей используются единые настройки маршрута и один общий процесс встроенного Tor; отдельными остаются экземпляры toxcore, профильные данные и очереди событий. Непрочитанные события фоновых профилей сразу отражаются в переключателе и суммируются в системном трее.

## Сборка

Подробная инструкция для всех трёх ОС и перечень зависимостей находятся в [BUILDING-PLATFORMS.md](BUILDING-PLATFORMS.md). Отдельное расширенное описание Windows-сборки сохранено в [BUILDING.md](BUILDING.md). Критичные требования установки Web-версии как Debian 13 + Nginx service, включая передачу реального client IP в фактически читаемый backend-ом header, перечислены в [web/installer/README.md](web/installer/README.md#release-critical-installation-invariants).

Команды полной нативной сборки:

```powershell
# Windows x64, PowerShell 7.6.5
pwsh -NoLogo -NoProfile -File .\scripts\Invoke-KaigenAutomation.ps1 -Task windows-portable
# Debian 13 x64, PowerShell 7.6.5 вызывает нативный AppImage runner
pwsh -NoLogo -NoProfile -File ./scripts/Invoke-KaigenAutomation.ps1 -Task debian-build
# macOS 11+, PowerShell 7.6.5 вызывает нативный universal runner
pwsh -NoLogo -NoProfile -File ./scripts/Invoke-KaigenAutomation.ps1 -Task macos-build
```

Результаты: `artifacts/Kaigen-portable-windows-x64.zip`, `artifacts/Kaigen-installer-windows-x64.msi`, `artifacts/Kaigen-portable-debian-x64.zip`, `artifacts/Kaigen-portable-macos-universal-UNSIGNED-TEST.zip`, `artifacts/Kaigen-Web-Debian13-Nginx-0.2.6.tar.gz`, отдельный bootstrap `artifacts/Kaigen-Web-Installer-0.2.6.sh` и `artifacts/Kaigen-source-github.zip`. MSI создаётся отдельным Windows CI-шагом из готового portable-каталога. Web-архив и bootstrap-инсталлер собираются отдельным Linux CI-заданием: bootstrap скачивает exact release bundle с GitHub и проверяет его SHA-256 до установки. Релизный macOS-архив без суффикса поддерживает `adhoc-release` (ad-hoc подпись, без нотарификации) и `distribution` (Developer ID и нотарификация); фактический режим указан внутри архива и в Release notes. Параметры приведены в `BUILDING-PLATFORMS.md`.

Клиент поддерживает PQ v2 поверх Tox E2EE: ML-KEM-768 + X25519, AES-256-GCM, направленные цепочки ключей сообщений и однократное автоматическое установление при первой отправке. Старые ключи сохраняются до завершения доставки; после ручного завершения PQ включается только вручную. Техническое описание, ограничения доверия и совместимости приведены в `POST_QUANTUM.txt`.

## Tor

Tor включён по умолчанию. Приложение запускает собственный исполняемый файл Tor из официального Expert Bundle для целевой ОС, ждёт фактического `Bootstrapped 100%` и только после этого разрешает сетевой цикл Tox. SOCKS5 и ControlPort выбираются динамически из свободных нестандартных портов, поэтому клиент не конфликтует с Tor Browser или другим Tor пользователя. В Tor-режиме UDP, локальное обнаружение, прямой TCP-маршрут и локальный DNS toxcore отключены. При ошибке Tor автоматического перехода на прямое соединение нет.

В одном portable-каталоге может работать только один экземпляр Kaigen. Копии из разных каталогов считаются независимыми и используют собственные `data`, Tor-процесс и динамические порты. Встроенный Tor завершается вместе со своим экземпляром Kaigen, не затрагивая Tor Browser и другие пользовательские процессы Tor.

Доступны режим без мостов, встроенные Snowflake и obfs4, а также пользовательские строки мостов, включая WebTunnel. Настройки и рабочие данные Tor хранятся в `data` рядом с приложением.

## Безопасность данных

Файлы `profiles\*\*.tox` содержат секретные ключи. Не публикуйте их, не добавляйте в Git и храните резервную копию в защищённом месте. Каталоги `data`, `profiles`, `downloads` и служебный кэш `Kaigen.exe.WebView2` также не должны попадать в публичный release с чистой установкой.

История экспортируется в общую для профилей папку `chat export` рядом с EXE. Экспорт всегда включает всю историю выбранного контакта и не зависит от лимита 20/50/100 сообщений, используемого для экономной загрузки чата в интерфейс.
