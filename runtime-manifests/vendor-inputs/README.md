# Pinned third-party build inputs

These immutable archives supply the existing managed component preparation route on clean Actions checkouts. They contain third-party Tor transport binaries and the public IPFire country dataset. Existing archive size and SHA-256 pins remain authoritative; missing cache objects can be seeded from these tracked copies, and invalid existing objects still fail verification.

Lyrebird 0.9.0 + Kaigen Snowflake 2.15.1 patch was compiled from the official Tor Project base source commit 89d54872b176f936232ff39f7a8189b77d83d65e using Go 1.27.2 for Windows/Linux and isolated Go 1.26.8 for macOS, with CGO disabled. The macOS universal binary includes x86_64 and arm64 slices with minimum macOS 12.0. All platform archives contain the upstream LICENSE (Tor Project/Go BSD notices); binary redistribution requires retaining these notices and does not require distributing corresponding source. Source: https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/lyrebird/-/tree/89d54872b176f936232ff39f7a8189b77d83d65e .

The limited Lyrebird patch-set and full module graph are pinned in patches/lyrebird. Snowflake is 2.15.1; Pion WebRTC 4.2.23 / DTLS 3.1.12 preserve the required nonce epoch/sequence security-fix behavior. These outputs are explicitly upstream-plus-patch builds.

Conjure helpers are separate overlays from the Tor PT fork snapshot 0090962226b82aa4a8fc38506f9b98de67d0781e. The nested Conjure 0.9.1 / uTLS 1.8.2 / Snowflake 2.15.1 versions and the working Kaigen torrc remain unchanged. Windows/Linux use isolated Go 1.27.2; macOS universal uses Go 1.26.8 and minimum macOS 12.0. All overlays retain the original license notices; the official Tor Expert Bundle 15.0.25 archives are unchanged.

GeoIP is the IPFire Project Location Database generated 2026-10-15T04:36:30Z, converted into Tor CSV with the unmodified official geoip-db-tool from Tor commit 8fe2745aee2c35116ff1081f19b2952418b43069. Dataset: https://location.ipfire.org/databases/1/location.db.xz . The archive retains CC BY-SA 4.0 license, attribution and conversion provenance; redistribution of this converted dataset follows the same license. License: https://creativecommons.org/licenses/by-sa/4.0/ .

provenance.json records source, toolchain and input/output identities without local cache paths or private service data. These inputs are used by the Actions producers; they are not Kaigen release assets.

Managed Linux CLI build inputs are source-only: the exact 125,346,612-byte source/vendor archive is stored as two numbered parts, each below GitHub regular-file size limits, plus the unmodified official tauri-cli 2.12.3 crate. `patches/tauri-cli/manifest.json` binds both part hashes/sizes and the assembled archive hash. `scripts/prepare-managed-tauri-cli.mjs build-seeded` verifies and atomically seeds these inputs, verifies complete source/vendor trees, and compiles offline with pinned Rust/Cargo 1.97.1. The Actions job runs inside the official Debian 13 slim image pinned by digest a29215f6a35e51e22adffa17f89e9d2ef06214e64a2bad10d765c46aea49f11f on an Ubuntu 24.04 hosted runner, and produces its own Debian-native CLI and binary provenance, which `admit-built` binds to the same job before AppImage packaging. No compiled local managed-CLI binary is included in these source inputs or substituted as an Actions release artifact.

The libsodium 1.0.22-stable source snapshot from 2026-10-13 is preserved as the unmodified upstream archive (`libsodium-1.0.22-stable-20261013.tar.gz`, 2,099,899 bytes, SHA-256 `eb9873cc5ccd7b26ef058394264663c99e9c047b423be1ffd484071774198f26`). Its included ISC license remains intact. The mutable upstream stable URL is not an immutable identity; clean Actions runners seed this exact verified archive through the existing missing-only cache route. Current Windows Lyrebird and Conjure overlays are also retained as exact pinned ZIP inputs with their license notices and identities in provenance.json.
