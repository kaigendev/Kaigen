# Kaigen Website

Публичный сайт проекта [Kaigen](https://github.com/kaigendev/Kaigen), доступный на семи языках.

## Локальный запуск и сборка

`npm run dev` запускает локальный Vite dev server. `npm run build` подготавливает публичные файлы и создаёт клиентскую сборку в `dist/client`. Локальная сборка используется для проверки; пакет для публикации производит GitHub Actions.

## Публикация

Сайт обновляется после опубликованного релиза Kaigen и подтверждённого Web production. Выбранный Actions publisher создаёт пакет сайта с manifest и SHA-256; сервер получает проверенный пакет из GitHub Release. Локальные служебные данные и `.ops.local` в пакет не входят.

## Данные релиза

`script.js` запрашивает точный тег `v0.3.3` через публичный GitHub API и обновляет версию, дату, ссылки скачивания и прогресс дорожной карты. При недоступности API используются встроенные ссылки на assets этого релиза: Windows MSI, portable-архивы Windows, Debian и macOS и Web-инсталлер 0.3.3.

Релиз опубликован 27 октября 2026 в 11:02:19 UTC. Пакеты для Windows, Debian, macOS и Web произведены GitHub Actions. Все платформы включают Tor 0.4.9.14 и Lyrebird 0.9.0. Для macOS требуется версия 12 или новее; приложение подписано ad-hoc, без нотариализации.

История сохраняет все прежние вехи, их переводы, даты и связи с релизами. Добавлена веха 0.3.3 на семи языках; по умолчанию видны все этапы.
